# Evaluación de Recursos Educativos Digitales

Sitio académico de Jesús Alberto Giraldo Zapata, preparado para publicarse en Netlify.

## Publicación

Netlify utiliza automáticamente la configuración de `netlify.toml`:

- Comando de construcción: `npm run build`
- Carpeta publicada: `out`
- Versión de Node.js: `22`
